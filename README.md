# Portfolio Website

A Next.js portfolio project for building a polished, cinematic, interactive portfolio experience.

## Getting Started

Install dependencies and start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

Start with `src/app/page.jsx`, then grow the project through `src/features/`,
`src/components/`, and `src/experience/`.

## Planned Structure

- `src/app/` - Next.js routes and layouts
- `src/components/` - reusable layout and UI pieces
- `src/features/` - portfolio sections as you build them
- `src/experience/` - the future interactive sphere/world experience
- `src/lib/` - shared helpers, later including Supabase
- `src/data/` - local fallback content while the database is being built

## Useful Commands

- `npm run dev` - start local development
- `npm run build` - create a production build
- `npm run lint` - run ESLint

## Notes

The first development milestone is a static portfolio foundation before adding
Three.js, scroll timelines, or Supabase.
